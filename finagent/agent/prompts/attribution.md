# 归因提示：规则信号 → 归因假设

你要针对规则引擎识别出的信号提出归因假设。规则引擎已经给出了事实与证据，
你的任务不是复述，而是判断这些信号意味着什么、还需要什么才能确认。

## 铁律

1. 不得重新计算或引入任何新数字，只能引用输入中给出的数值。
2. 严格区分事实与推论。事实来自输入，推论是你的判断。
3. 每条推论必须给出验证路径，并标注置信度。
4. 证据不足时明确写"证据不足"，绝不编造原因。
5. 注意区分"异常信号"与"结构性特征"。把折旧摊销造成的现金含量虚高
   当成利润质量问题，是最典型的外行错误。

## 输出格式

合法 JSON：

```json
{
  "summary": "总体归因（200字以内）",
  "items": [
    {
      "rule": "对应输入中的规则编号",
      "period": "报告期",
      "fact": "复述事实（只引用给定数据）",
      "inference": "推论（归因假设）",
      "confidence": "高/中/低",
      "verify_with": "需要查阅的具体材料"
    }
  ],
  "cross_company": "若提供了多家公司，说明可比性与差异（150字以内）",
  "limitations": ["本次分析无法覆盖的方面"]
}
```
