# 团队协作说明

本文面向**队友**：怎么把项目跑起来、怎么分工、怎么保证两个人在两台机器上跑出同样的结果。

> **一句话前提：每个人在自己电脑上独立运行，不需要和任何人处于同一局域网。**
> 服务只监听本机 `127.0.0.1`，各自的 Key、各自的财报、各自的产物，互不依赖。

---

## 一、跑起来（三步）

```bash
git clone https://github.com/ZhengChen1227/finagent.git finagent
cd finagent
```

然后：

```
双击  一键安装依赖.bat        # 仅首次：建 .venv、装固定版本依赖、环境自检
双击  启动FinAgent应用.bat    # 每次：启动服务并自动打开浏览器
```

界面右下角（右上角「设置」）填自己的 DeepSeek API Key，拖入财报 PDF，点「开始分析」。
完整操作说明见 `docs/使用指南.md`。

> 想手动来也行：
> ```bash
> python -m venv .venv
> .venv\Scripts\python.exe -m pip install -r requirements.txt
> .venv\Scripts\python.exe app\server.py --port 8765
> ```

## 二、密钥配置

### 方式 A：界面里填（推荐）

点右上角「设置」，填 API Key，选模型，点「测试连接」→「保存」。
密钥写入本机 `config.local.yaml`，该文件在 `.gitignore` 中，**不会进版本库**。
界面回显时密钥打码，只保留首尾几位。

### 方式 B：环境变量（适合临时切换）

```powershell
$env:FINAGENT_API_KEY = "sk-xxxx"
$env:FINAGENT_BASE_URL = "https://api.deepseek.com/v1"   # 固定，改不了
$env:FINAGENT_MODEL = "deepseek-chat"
```

配置优先级：内置默认值 < `config.yaml` < `config.local.yaml` < 环境变量。

**没有密钥就是不能分析。** 这不是待修的问题：没有 Key 时点「开始分析」会被直接拦截
并弹出密钥窗，系统**不产出任何替代结论**，也不存在离线降级路径。

## 三、财报材料

材料**不入库**，每人自己准备。推荐按 `docs/复现清单.md` 从巨潮资讯网下载，
清单里给了每份公告的标题、链接、公告编号与 SHA256，下完校验哈希即可确认是同一条。

**不要**把财报 PDF 提交进仓库：单份最大 6.7MB，36 份共 74MB，而且属于第三方披露文件。

两个人要复现同一结果，**必须用同一份文件**（同一公告、同一版本）。用 SHA256 对齐最省事。

## 四、分工建议

| 角色 | 主要工作面 |
|---|---|
| 抽取与口径 | `finagent/ingest/`、`finagent/datasource/` |
| 指标与校验 | `finagent/metrics/`、`finagent/validate/` |
| 智能体与报告 | `finagent/agent/`、`finagent/report/`、`finagent/corpus/` |
| 界面与演示 | `app/`、`docs/`、计划书与介绍视频 |

无论怎么分，提交前都要跑：

```bash
python tests/run_all.py      # 11 套测试
```

**判读原则**：跳过说明"前置条件还没做"，失败才说明"功能坏了"。

- `抽取层(合成版面)`、`网络边界`、`规则引擎`、`工具层`、`编排循环`、`MCP 协议`
  等套件在任何机器上都能跑，不依赖第三方材料；
- 涉及真实财报复算的集成用例，本机没有 `data/` 语料时会**明确跳过并打印提示**，
  不会伪装成通过。

## 六、常见问题

**Q：我和队友需要连同一个 WiFi 吗？**
不需要。各跑各的，服务只监听 `127.0.0.1`。要互相给结果就传 `output/` 里的产物文件。

**Q：界面显示"未配置密钥"，但我明明填了？**
检查是否点过「保存」。读写的是项目根目录 `config.local.yaml`，确认该文件存在且 `api_key` 非空。

**Q：某份 PDF 上传后主体识别为空？**
多半是摘要版 / 摘编版，没有封面页；扫描件则没有文本层，会被直接拒绝。
换完整版定期报告。文件名保留原始公告名可以作为兜底线索。

**Q：报告里出现「需人工复核」是什么意思？**
该科目没通过交叉校验闸门（同比对不上 / 资产 ≠ 负债 + 权益 / 小计 ≠ 明细之和）。
这是特性不是 bug：系统宁可标注可疑，也不静默输出可能错位的数字。
打开轨迹页可以看到具体是哪一步没过。

**Q：两人跑同一批财报，结果会不一样吗？**
确定性层（抽取、指标、校验、规则、报告的数值部分）**逐字节一致**，
`tests/test_reproducibility.py` 就是拿两次运行做逐字节比对的。
可能不同的只有"归因推理"那一段——它依赖大模型，因此报告里与事实分区呈现，
轨迹中也记录了模型名、prompt 哈希与温度。

**Q：报告里的数字能追到出处吗？**
能。每个数值带证据编号与页码，报告引用原文时标注页码，可用 `read_page` 工具逐字核对。
