# 界面截图

本目录是**真实运行**截图，不是效果图：用无头 Edge 打开本地服务
（`app/server.py`，监听 `127.0.0.1:8765`），上传三份真实半年报，
跑完一次完整分析后逐页截取。采集过程见 `AGENTS.md` 的复现清单，
控制台报错数为 **0**。

材料：牧原股份 2026 半年报、京东方 A 2026 半年报、贵州茅台 2026 半年报。
三份材料共 506 页正文，抽取 153 个科目，交叉校验 0 项未过。

## 说明

- `04` 与 `05` 需要先在左栏选中一份报告 / 一次运行，否则右侧是空态。
- `07` 是用报告页的「下载 PDF」按钮导出的成品，未做任何后期处理；
  版式由本机 Edge 的打印引擎生成，不引入第三方 PDF 排版库。
- 截图会随界面改动而更新；若与当前界面不一致，以代码为准。
