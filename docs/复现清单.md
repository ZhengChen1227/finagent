# 复现清单

> 本文件回答一个问题：**评审方要在自己的机器上复现 FinAgent 的结论，需要哪些材料、从哪来、怎么确认拿到的是同一份。**

---

## 一、为什么仓库里没有财报

财报 PDF 是第三方披露文件：36 份共约 74MB，单份最大 6.7MB，且会随时间新增修订版。
把它塞进仓库既拖慢克隆，也无法保证评审拿到的是**我们测试时的那一版**。
因此改为：**清单 + 哈希**。你按下面的链接自行下载，用 SHA256 校验，即可确认与我们的基准完全同源。

## 二、怎么校验

PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 .\2026-08-21_semi_1225485220.PDF
```

或 cmd：

```
certutil -hashfile 2026-08-21_semi_1225485220.PDF SHA256
```

哈希一致 = 同一份文件。哈希不一致说明拿到了修订版，表内数字可能不同，请以你手上的版本为准重新核对。

下载下来的文件建议按 `data/corpus/<股票代码>/<公告日期>_<类型>_<公告编号>.PDF` 命名放置，
这样可以直接用 `python run.py analyze --pdf-dir data/corpus/002714` 跑批。
